新建任务

填截帧在本机上的完整路径（.rdc 通常有 1–2 GB，页面不复制它，只在 workspace/ 下登记一个任务目录）。 新建后自动跑「截帧分析」，之后在工作流里继续。

重命名任务

只改显示名。目录名 保持不变——UE 的 /Game/RenderForge/<目录名>、 Unity 的 Assets/RF/<目录名> 和已生成的截图文件名都由它派生，改目录名会让已有的引擎导入失联。
